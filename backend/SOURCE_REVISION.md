# Backend source snapshot

- Upstream repository: https://github.com/cirvannaco-png/Midas-touch2-.git
- Upstream branch: main
- Upstream commit: 41b668485336fd8ebc2267bb4f34c23826af7191
- Snapshot directory: backend/source/

This is a byte-for-byte working-tree snapshot of the upstream repository,
excluding only its Git object database. It preserves source code, tests,
migrations, documentation, deployment manifests, workflows, and research
tooling. Workflows under backend/source/.github/ are preserved as provenance;
GitHub Actions executes only workflows under the root .github/ directory.

The snapshot does not claim that every backend capability is already wired
into the root MT5 EA. Runtime integration, independent validation, and
production readiness remain separate gates.
