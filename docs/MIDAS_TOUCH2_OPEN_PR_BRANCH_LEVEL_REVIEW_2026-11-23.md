## Midas implementation work from this review

1. **Margin admission:** Midas-native account-wide admission is implemented in the active EA and the imported bridge service overlay. The 20% free-margin buffer is configurable; snapshots and required margin fail closed; account-wide serialization and snapshot-aware pending/fill accounting are covered by regression tests. See `docs/MIDAS_MARGIN_ADMISSION_IMPLEMENTATION.md`.
2. **Broker retcodes:** `TRADE_RETCODE_PLACED` is no longer treated as completed for management operations. New market/limit order requests may be accepted as placed; modification, deletion and close actions require completion retcodes.
3. **Production authentication:** deferred pending a Midas-specific trust boundary and deployed service. See `docs/MIDAS_PRODUCTION_AUTH_SECURITY_REVIEW.md`.
4. **Research:** all research candidates remain non-default and retain their original cost, attribution, sample, and holdout limitations.
